# /plan-status — 企画書の進捗確認

`output/draft.md` のフロントマターから進捗ステータスを読み取ります。**ファイル本文は読みません**ので、長い対話の途中でも安全に呼び出せます。

## 動作

`template-writer` をモード2（レジューム読み取り）で起動:

> Task: template-writer
> モード: レジュームチェック
> output/draft.md のフロントマターのみ読んで返してください。

## 表示

返ってきた情報を以下のフォーマットでユーザーに見せる:

```
📋 サービス企画の進捗

✅ 完了済みフェーズ: {N} / 4

  フェーズ1（体験・真因）: ✅ 「{phase1_truth}」
  フェーズ2（ユーザー・競合）: ✅ 「{phase2_user}」
  フェーズ3（価値・MVP）: ⬜ 未完
  フェーズ4（展開・技術）: ⬜ 未完

最終更新: {last_updated}

▶ 続きを始めるには `/plan-service` を実行してください。
```

ファイルが存在しない場合:
```
📋 まだ企画書は作成されていません。
▶ `/plan-service` で開始してください。
```
